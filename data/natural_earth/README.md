# Natural Earth 1:110m land polygons

The shapefile components in this directory are Natural Earth physical-vector
data, layer `ne_110m_land`, version 4.1.0.  They are used only to draw the
continent outlines in `src/plot_mars_earth_toomre.py`.

Source: <https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/>

Natural Earth data are in the public domain.  See
<https://www.naturalearthdata.com/about/terms-of-use/>.
